# 独热编码

独热编码（one-hot）把一个离散符号（一个词、一个类别）表示成一个向量：长度等于词表大小，只有这个符号对应的那一位是 1，其余全是 0。它是符号变成数字最朴素的办法。

## 为什么需要它
模型只吃数字，但「猫、狗、鸟」这类符号本身没有大小关系。直接编成 1、2、3（label encoding）会凭空造出「猫 < 狗 < 鸟」、「鸟 − 狗 = 狗 − 猫」这种假关系。one-hot 让每个符号各占一维，谁也不比谁大。

## 怎么运作
词表 = `[我, 喜欢, 猫]`
- 我 = `[1,0,0]`
- 喜欢 = `[0,1,0]`
- 猫 = `[0,0,1]`

两个关键性质：
1. **维度 = 词表大小**：几万维，而且每个向量只有一位非零。
2. **两两正交**：任意两个不同的词点积都是 0，「猫」和「狗」的距离跟「猫」和「喜欢」一样。

## 容易搞混的
- **和词袋模型**：one-hot 表示一个词，词袋表示一段文本。把每个词的 one-hot 向量相加，就得到词袋向量。词袋「维度大、词之间正交」的缺陷都继承自 one-hot，只有「丢语序」是求和这一步额外带来的。
- **和词嵌入**：one-hot 向量乘以嵌入矩阵 E，结果正好是 E 的一行。所以 Transformer 输入层的「查嵌入表」，就是 one-hot × 矩阵的省事写法，框架直接按下标取行。词嵌入把稀疏、正交的 one-hot 压成稠密、近义词挨得近的向量。
- **不是 NLP 发明的**：统计学里的 dummy variable、数字电路里状态机的 one-hot 编码都比 NLP 用得早，所以它没有一个「出现在哪一年」的答案。

## 线头
- 词袋模型：one-hot 的求和
- 词嵌入 / 嵌入表：one-hot × 嵌入矩阵，也就是查表
- 统计学：dummy variable，类别特征进回归模型的标准做法
- 数字电路：状态机的 one-hot 状态编码
- softmax / 交叉熵：分类任务的目标标签通常就是 one-hot 向量
