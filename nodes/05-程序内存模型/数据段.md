# 数据段

数据内存。在汇编代码的 data 段定义的数据（编译时已存在的数据、静态数据）。由汇编器 `.data` 定义。

> 补充自《ELF》（2026-09-24）：已有节点只说数据段由 .data 定义，缺 .data / .bss / .rodata 的区分

### 在 ELF 里的细分

汇编的 `.data` 在 ELF 里对应 `.data` 节（`PROGBITS`，标志 `WA`），只放**已初始化**的全局/静态变量。另外两个相邻的节：

- `.bss`（`NOBITS`，`WA`）：未初始化的全局/静态变量，文件里不占空间；加载时 `p_filesz < p_memsz` 的差额被清零，就是它
- `.rodata`（`PROGBITS`，`A`）：只读常量、字符串字面量、跳转表

运行时它们按权限被合进 R 或 RW 的 `PT_LOAD` 段。
