# 代码段

代码内存 / 指令段。存放指令（程序的指令流），指令片段之间互相调用使用 call。由汇编器 `.text` 定义。

> 补充自《ELF》（2026-09-24）：补上代码段在 ELF 文件与加载后的权限

### 在 ELF 里

`.text` 节类型 `PROGBITS`、标志 `AX`（分配内存 + 可执行）。加载时被放进权限为 R + X 的 `PT_LOAD` 段——可执行但不可写。
