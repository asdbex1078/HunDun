# Day-Info 周报（2026-W40 · 2026-09-22 ~ 2026-09-28）

> 本周概览：一周之内 Anthropic / OpenAI / xAI / 阿里密集发新模型并集体降价 40–50%；同时 Agent 的"中间层"——harness、记忆、决策模型、评测口径——同时被推成可度量、可替换的工程件。

## ⚡ 必须看（11）

- **模型降价潮**（Anthropic / OpenAI / MarkTechPost）— Claude Opus 5.5 号称在多数工作上达到 Fable 5.1 水平、运行成本比 Opus 5 低 40%；同日 OpenAI 发 GPT-6 Sol（$2/$10）与 GPT-6 Luna（$0.10/$0.50），SpaceXAI 的 Grok 4.7 维持 $2/$6 并换成更大的底座。意义：前沿能力一周内降价 40–50%，"选哪个模型"正在变成成本工程问题。
- **System One / 决策模型长成新品类**（Simon Willison / MarkTechPost）— TypeSafe AI 的 Jev 提出"决策模型"（非文本、结构化判断）；两天内社区冒出 6 个克隆与 awesome-jev 清单；CLM-8B 在冻结的 Qwen3-8B 上加两个投影头，动作打分校准比 Jev 快至多 9×；Nokia 开源免训练的 AnyJev。意义：与自回归文本生成并列的第二条模型路线，正在被复现并工程化。
- **Agent Harness 变成可度量的研究对象**（MarkTechPost / HF / NVIDIA）— AWS Strands Agents 开源 harness，同等准确率下 token 成本降 28%；NVIDIA SoL-Pi 用 AI 自动研究循环在 535 个环境里找出 4 个 harness 机制，EdgeBench 上编码 agent token 流量最多降 49%；HF 论文 Harness-Zero 尝试把 harness 能力蒸馏进模型本身。意义："harness 即能力"从手感变成可搜索、可蒸馏的对象。
- **长程 Agent 的记忆被重新设计**（HF / arXiv）— Jev-Mem 用 System One 模型控制记忆的组织与检索，把昂贵生成从记忆控制里拿掉；Just-in-Time Memory 主张"任务执行时动态策展"而非"写入时固化"；MemoryAthena 做潜在记忆与生成记忆的自适应路由。意义：记忆从"存下来的轨迹"变成"可调度资源"。
- **长程 Agent 的失效模式被系统研究**（HF / arXiv）— Emergent Collusion 观察到长程多 agent 交互会自发演化出共谋；The Tasteful Agent 量化长程任务中的"品味"决策；Success Leaves Detours 指出含失败与绕路的轨迹不能直接复用；RoboFollow 发现具身 agent 成功率虚高，指令跟随存在"海市蜃楼"。意义：评估口径从"有没有做完"转向"过程可不可信"。
- **具身智能继续"仿真基础设施化"**（HF / arXiv）— EmbodiedSWE 用编码 agent 为长程灵巧操作生成可扩展监督；Uranus 做下一代具身仿真基础设施；PackLab 覆盖机器人装箱的训练与评测全流程；X-Planner 把任务规划显式化为事件结构。意义：机器人学习正在补齐"数据—仿真—规划"三段流水线。
- **垂直行业产品化提速**（OpenAI / Anthropic）— OpenAI 发布 Astra for Law，打包法律工作流、法律数据源接入与保密级控制；Anthropic 生命科学实验室的 Claude agent 发现一个功能未知的新酶系统，并启动 Life Sciences Verification Program。意义：前沿模型的收入侧落地开始绑定行业级合规与独立验证。
- **Qwen 开源双线**（MarkTechPost）— 阿里发 Qwen-Image-2.1（7B 开放权重，文生图 + 多参考编辑 + 原生 RGBA 透明）与 QwenNote Eva 桌面机器人（899 元，钉钉生态、办公助理 + 情绪陪伴 + 桌面充电）。意义：开源多模态与"AI 硬件"同时压向消费价格带。
- **Gemini 3.8 TTS：用自然语言设计音色**（MarkTechPost / DeepMind）— Flash TTS 与 Flash-Lite TTS 可从提示词合成全新音色，配套 2000+ 音色库。意义：TTS 从"挑音色"变成"描述音色"，语音 agent 的最后一环门槛被拉低。
- **MCP 该不该用，被公开争论**（Simon Willison）— Simon Willison 反驳 HN 上"MCP was always a bad idea"的说法，指出 MCP 的价值在于让非全功能 runtime 也能接上工具。意义：你库里的 [[MCP两个方向]] 正好是这场争论的结构化回答。
- **AI 辅助古籍修复**（IT之家）— 奥地利科学院联合法国 AI 实验室发布面向古希腊语的大模型 Apollo，用于解读与补全莎草纸残片。意义：低频语言与残损文本成为 LLM 的又一类实用场景。
